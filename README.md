# ScrubSend – legal and support pages

Static pages for the Android app **ScrubSend** (`de.scrubsend.app`): privacy notice, legal
notice (Impressum) and support, in German and English. Published through GitHub Pages.

- `index.html` – landing page
- `privacy.html` – privacy notice (`#de`, `#en`)
- `impressum.html` – Impressum / legal notice (`#de`, `#en`)
- `support.html` – support and FAQ (`#de`, `#en`)
- `styles.css` – the only stylesheet; no JavaScript, no external resources

The texts describe the app's actual behaviour and are updated together with the app.
